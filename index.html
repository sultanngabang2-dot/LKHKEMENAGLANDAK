Cara Membuka Website Ini Online Gratis di GitHub Pages

Aplikasi ini berbentuk Single-Page File sehingga bisa langsung di-onlinekan tanpa perlu menyewa web hosting berbayar.

  1. Simpan File: Simpan atau download kode ini dan beri nama file persis index.html.
  2. Buat Akun & Repo di GitHub: Masuk ke github.com, lalu klik New Repository.
  3. Beri nama repositori (contoh: lkh-madrasah) dan pilih Public.
  4. Upload File: Klik menu Add file > Upload files, seret file index.html yang tadi, lalu klik Commit changes.
  5. Aktifkan GitHub Pages:
    • Buka tab Settings di repositori Anda.
    • Pilih menu Pages di bilah samping kiri.
    • Pada bagian Branch, ubah None menjadi main atau master, lalu klik Save.
  6. Tunggu 1-2 menit. Repositori Anda akan memiliki link publik seperti:
    https://username-anda.github.io/lkh-madrasah/
